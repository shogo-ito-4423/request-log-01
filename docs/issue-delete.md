# B4：指定した改善要望を削除できるようにする

対象はM2。依存するA1（Issue #1）は完了。見積もりは45〜60分。

登録済みの改善要望は取得・更新できるが、誤登録した要望を取り除く操作がない。`DELETE /issues/{id}` で指定した1件を物理削除する。利用者は「要望があったこと自体を取り消す操作のため」と判断した。応答は以下の完了条件のとおり。

## 完了条件

- 削除成功時は `204 No Content` を返し、レスポンス本文が空であることをテストする。
- 最初から存在しないIDへの削除と、削除済みのIDへの再削除は、どちらも既存の詳細取得と同じ `404 Not Found` を返す。両ケースでステータスとエラー本文をテストする。
- Alembicで構築した使い捨てSQLiteに2件登録し、片方を削除する。別リクエストで詳細と一覧を取得し、対象が取得できず、もう片方は元の内容で取得できることを確かめる。
- READMEに削除操作と応答例を記載し、Docker内で既存・追加のpytestとRuffのチェックが通る。

使用する技術はFastAPI、SQLAlchemy Session、pytest、Docker Compose。PostgreSQLでの全CRUDのCI検証は後続のB5で扱う。
