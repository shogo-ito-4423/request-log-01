# 業務改善リクエスト管理APIの1日版を実装

改善要望を登録し、一覧・詳細で確認して担当者・優先度・進捗を更新できるようにする。
SQLiteをDockerの名前付きボリュームに保存し、コンテナの再作成後もデータを保持する。

## 変更内容

- FastAPI / SQLAlchemyによる5つのエンドポイントと入力検証。
- 省略フィールドを保持するPATCH、404 / 422、ページ分割、UTC日時。
- 非root実行のDockerイメージとCompose、ハッシュ付き依存ロック。
- Ruff、pytest、実HTTP通信とコンテナ再作成を検証するGitHub Actions。
- 日本語README、設計判断、操作・検証手順。

## 検証

CIの実行結果を確認してからマージする。
